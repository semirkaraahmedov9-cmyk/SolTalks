# Тази поправка винаги е по-важна от големия речник.
#
# КАК: по една дума на ред, с малки букви,
#      а ударената гласна – с ГЛАВНА буква:
#
#        зарАди          (= зара̀ди)
#        солидАрността   (= солида̀рността)
#
# - Пишете точно формата, която чувате грешно:
#   „книга“, „книгата“ и „книгите“ са три различни реда.
# - Имената също: ИвАн, ЧепИнци (главната първа буква не пречи).
# - Всичко след знака # е бележка и не се чете.
#
# След промяна: пуснете "npm run test" – тестът казва, ако някой ред е сгрешен.
#
# (English: one word per line, lower case, stressed vowel in CAPITALS.
#  These fixes always win over the big stress list.)
